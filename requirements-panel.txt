# CINEMORA backend dependencies — PANEL (Pterodactyl/generic-python) hosts.
#
# This is backend/requirements.txt MINUS the Manim source-build tree.
# manimpango and pycairo publish no prebuilt wheels: they compile against
# system Pango/Cairo libraries that generic panel images do not carry, so
# a pip install of the full file aborts partway on such hosts and leaves
# the environment half-empty (the 2026-11-26 Nodaroo failure: pip died on
# the Manim tree and even alembic was missing at startup). Every pin below
# installs from a prebuilt wheel on CPython 3.12 (verified by a binary-only
# resolution of the full set) — srt is the one sdist-only pin, and it is
# pure Python, so it installs anywhere.
#
# What the panel host loses: only the Manim motion-graphics renderer.
# services/motion_engine/manim_templates.py never imports manim itself;
# without it those templates refuse with the typed "manim_unavailable"
# reason and the PIL/matplotlib template families carry production, by
# design. Docker and CI keep using backend/requirements.txt (the image
# installs the cairo/pango system packages first).
#
# Keep this file in sync with backend/requirements.txt minus the excluded
# set — tests/test_panel_requirements.py enforces exactly that.
# Excluded: manim, manimpango, pycairo, moderngl, moderngl-window,
# glcontext, pyglet, pyglm, skia-pathops, isosurfaces, svgelements,
# mapbox-earcut, screeninfo, cloup, pydub (manim-tree only).
