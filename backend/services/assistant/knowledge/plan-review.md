title: Plan review and sentence decisions
link: /projects/[id]/plan
keywords: plan, review, approve, sentence, decision, replace, regenerate, visual plan

The Plan tab shows the sentence-level visual
plan for a project: for every sentence of the script, the visual
the planner proposes and, after production, the visual that was
chosen, with its evidence.

For each sentence you can record a decision:

- approve — accept the proposed/chosen visual.
- replace — supply a replacement (an uploaded file or a source
  URL). After a completed run, a replacement file goes
  through the same evidence checks as any pipeline visual before
  it is swapped in; the outcome is recorded either way.
- regenerate — mark the sentence to be regenerated on the next
  run.

If a run is parked awaiting plan approval (because the production
was submitted with plan approval required), the Plan tab is where
you review it; approving the plan releases the run into full
production, carrying any regenerate marks with it.
